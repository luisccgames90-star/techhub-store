# 🚀 TechHub Store - Tienda Tecnológica

Una tienda tecnológica moderna con panel administrativo integrado, construida con HTML5, CSS3 y JavaScript puro.

## ✨ Características

### 🛍️ Front-end (Clientes)
- Catálogo de productos tecnológicos
- Búsqueda y filtros por categoría
- Carrito de compras funcional
- Sistema de favoritos
- Proceso de checkout completo
- Diseño responsive y moderno
- Animaciones y efectos visuales premium

### 🔧 Back-end (Administración)
- Panel de control completo
- CRUD de productos
- Gestión de categorías
- Gestión de pedidos
- Estadísticas en tiempo real
- Exportación de datos
- Diseño separado del cliente

## 🎨 Tecnologías Utilizadas
- **Frontend**: HTML5, CSS3, JavaScript Vanilla
- **Diseño**: CSS Grid, Flexbox, Glassmorphism
- **Animaciones**: CSS Transitions, Keyframes
- **Almacenamiento**: LocalStorage
- **Icons**: Font Awesome 6
- **Fuentes**: Google Fonts (Inter)

## 🚀 Despliegue

### GitHub Pages (Recomendado)
1. Fork este repositorio
2. Ve a Settings → Pages
3. Activa GitHub Pages desde la rama main
4. Accede a: `https://[username].github.io/techhub-store/`

### Netlify
1. Conecta este repositorio a Netlify
2. Configura build settings (vacío para HTML estático)
3. Deploy automático en cada push
